# Next.js + PostgreSQL + Redis Starter

Deployed with **HostifyCloud**.

## 💻 Local Development

1. **Clone this repository**:
   ```bash
   git clone https://github.com/mahedimukut/nextjs-postgresql-redis-v2.git
   cd nextjs-postgresql-redis-v2
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Run local dev server**:
   ```bash
   npm run dev
   ```

## 🚀 Push to Deploy
Any commit pushed to `main` triggers automated zero-downtime builds on HostifyCloud:
```bash
git add .
git commit -m "feature update"
git push origin main
```
